## Manual Testing Instructions

For human testers who want to verify the feature end-to-end:

1. **Start the application:**
   ```bash
   npm run dev
   # Opens on http://localhost:3007
   ```

2. **Create a test session:**
   - Navigate to http://localhost:3007
   - Add 3+ members with different revenue amounts
   - Add some shared expenses
   - Choose distribution mode (EQUAL, PERCENT, or ADJUSTABLE)

3. **Export PDF:**
   - Scroll to results section
   - Click "Export PDF" button
   - Verify PDF downloads automatically

4. **Verify PDF content:**
   - Open the downloaded PDF
   - Check session header (name, date, type, revenue)
   - Verify member breakdown table (all members, correct amounts)
   - Verify settlement transfers (if any)
   - Check A4 formatting and readability

5. **Test German language:**
   - Toggle language to German (DE)
   - Click "PDF exportieren"
   - Verify PDF with German number formatting

See `verify-pdf-export.mjs` or `manual-verification-report.md` for detailed checklist.
